# Pochinko Budget Tracker 🪙🎰

**Pochinko** is a modern, interactive, and engaging financial management web application built to make budgeting intuitive, visual, and rewarding. Inspired by dynamic gaming elements and sleek modern web interfaces, Pochinko turns daily expense tracking and financial planning into an empowering habit.

---

## 🎯 Our Goals & Vision

1. **Gamified & Intuitive Financial Health**
   - Eliminate the friction and stress of manual expense tracking by presenting finances through dynamic visual dashboards, interactive goals, and instant visual feedback.

2. **Smart Allocation & Savings Planning**
   - Provide flexible mechanisms for setting monthly budget targets, organizing recurring payments, and mapping out long-term savings plans.

3. **Real-time Insights & Analytics**
   - Offer breakdown charts (powered by Recharts) for clear cash flow visibility, category distribution, and spending trends.

4. **Seamless Cloud Synchronization**
   - Support fast local state management (via Zustand) with cloud persistence (via Supabase) so financial records remain secure and accessible across devices.

5. **Gamified Milestones & Gamification**
   - Celebrate savings milestones and budget discipline with celebratory animations (canvas-confetti) and progress tracking.

---

## ✨ Key Features

- 📊 **Dynamic Dashboard**: Overview of total income, expenses, net balance, and active budget goals.
- 💳 **Transaction Tracking**: Add, categorize, filter, and track daily income and expenses.
- 🎯 **Savings & Payment Plans**: Create dedicated budget buckets and track recurring obligations with visual progress indicators.
- 📈 **Visual Analytics**: Interactive category distribution charts and balance trends.
- 🌙 **Modern Dark UI**: Designed with Tailwind CSS v4 for a sleek, responsive, and engaging aesthetic.

---

## 🚀 Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS v4, Lucide React (Icons)
- **State Management**: Zustand
- **Database / Backend**: Supabase
- **Charts & Visualization**: Recharts
- **Effects**: Canvas Confetti

## 🛠️ Local Setup & Development

```bash
# 1. Clone the repository
git clone https://github.com/Kaeylrin/pochinko-budget-tracker.git
cd pochinko-budget-tracker

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```
